# AI Sentiment Analysis using RNN and LSTM

An end-to-end Natural Language Processing project that classifies movie reviews as positive or negative using an LSTM-based recurrent neural network.

## Technologies

- Python
- TensorFlow
- Keras
- NumPy
- Pandas
- Matplotlib

## Key Concepts

- Natural Language Processing
- Text preprocessing
- Sequence encoding
- Padding
- Word embeddings
- RNN
- LSTM
- Dropout
- Early stopping
- Model evaluation

## Workflow

Movie Reviews  
↓  
Text Preprocessing  
↓  
Sequence Encoding  
↓  
Padding  
↓  
Word Embedding  
↓  
LSTM  
↓  
Classification  
↓  
Sentiment Prediction

## Model Optimization

The model uses the Adam optimizer, dropout regularization and early stopping to improve model generalization and reduce overfitting.

## Project Objective

The objective is to build an end-to-end deep learning pipeline capable of classifying movie reviews based on their sentiment.

## Disclaimer

This project is created for educational and machine-learning practice purposes.
